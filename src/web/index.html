自局

I-Gate の一般的な設定は テーブル「I」(オーバーレイ)＋シンボル「&」です。

出力・アンテナ (PHG)

アンテナ高は海抜ではなく、周囲の平均的な地表からの高さ (HAAT) です。各値は PHG の 1 桁コードに丸めて送ります (出力 0/1/4/9/16/25/36/49/64/81 W、高さ 10×2ⁿ ft)。通達範囲は APRS 規格の目安の式で計算した値で、指向性アンテナでも円で表示します。PHG を付けるとコメントは 36 文字までです。

APRS-IS

主につながらないときは副、副もだめなときは予備に自動で切り替えます。接続が切れたときは、また主から順に試します。複数のサーバーに同時にはつなぎません。ホスト名 (rotate.aprs2.net など) の指定を推奨します。

例: m/50 (自局から半径50km)、r/35.68/139.76/100、b/JA1XXX* など

TNC (RF)
TXDELAY / Persist / SlotTime / TXTail / Full Duplex は、TNC に接続するたびに KISS コマンドで送ります。
ゲート

JA1ABC は SSID なしの局のみ (JA1ABC-2 などは送出しません)。JA1ABC-* は全 SSID、JA1ABC-9 はその SSID のみ、JA3* は前方一致。

APRS-IS で受けた位置情報を、RF へサードパーティ形式で送出する条件です。局指定・ポジションコメントのうち、設定したもののどちらかに合う局だけを送出します。すべて空欄なら位置情報は送出しません (従来のローカル局宛メッセージのゲートだけ動きます)。すでに RF で聞こえている局は送りません。ポジションコメントは Mic-E の状態 (In Service・En Route など) で、選んだ状態の局だけに合います。「IS→RF 最大 (件/分)」の上限と送信パスを共用します。

宛先 (APDPRS・APDG??・API???・APD5T? など D-STAR 機器・ゲートウェイのもの) で判定します。シンボルの「D」だけでは判定しないので、D-STAR 以外の局は除外されません。除外した局は下の「除外局」と同じく、一覧・地図・メッセージ・DX・IS への転送・デジピートの対象外になります。

ここに書いた局は完全に無視します。RF・APRS-IS どちらの受信もなかったことにし (一覧・地図・メッセージ・DX・IS への転送・デジピートの対象外)、その局宛のメッセージも送りません。カンマ区切り。JA1ABC は全 SSID、JA1ABC-9 はその SSID のみ、JA3* は前方一致。

デジピータ

UIflood: KN3-3 のような地域限定パスを、自局コールを入れずに残りホップだけ 1 減らして中継します (KN3-3 → KN3-2 → … → KN3*)。UItrace: TRACE3-3 のようなパスを、自局コールを残しながら 1 減らして中継します (TRACE3-3 → 自局*,TRACE3-2)。どちらもカンマ区切り・英字のみで、n は 1〜7 です。既存の中継局と範囲が重ならないか確認してから設定してください。

WIDE1-1 の中継 (フィルインデジ) で、モービル機やハンディ機に自局パケットの中継が返り、電測に使えます。WIDE2-n の中継は送信が増えるため、高所設置の局などで地域の運用ルールを確認してから有効にしてください。TNC 接続時のみ動作します。

ビーコン
ウェザーステーション (Davis / rtl_433)

928.15〜929.65 MHz の 16 チャンネルを同時に受信します (日本仕様)。気圧はコンソールからしか得られないため、SDR 受信では送信されません。雨量は起動後の増分を積算します。

β版です。rtl_433 (別途インストール) を起動し、JSON の出力から気温・湿度・風・雨量・気圧・照度を読み取ります。近くに別のセンサーがあるときは model と id で使うものを絞ってください (下に受信できたセンサーが表示されます)。雨量は rtl_433 の積算値の増分から求めます。

CWOP (Citizen Weather Observer Program) へ気象データを送ります。ID は CWOP に登録した CW1234 形式の番号、またはアマチュア局のコールサイン-SSID (例 JA1XXX-13) です。パスコードは、CW1234 形式の ID なら不要、コールサインなら APRS-IS のパスコード (空欄なら自局のパスコード) を使います。送信間隔は 5 分以上です (10 分程度を推奨)。

コンソールにつないだデータロガーから約 2 秒ごとに現在値を読み取り、自局とは別の SSID の気象局として位置付きの APRS WX パケットを送ります (RF の送信パスはビーコンと同じ)。TNC 用とは別のシリアルポートを指定してください。WeatherLink など他のソフトが同じロガーを使っていると読み取れません。気圧はコンソールが標高補正した海面気圧を、雨量は 0.01 インチ単位の雨量計の値を使います。1 時間・24 時間雨量と突風 (過去 5 分間の最大風速) は読み取った値から積算するため、起動直後は実際より少なくなります。

最長距離 (DX)

RF で直接受信した局 (デジピート経由・オブジェクト・位置あいまいを除く) のうち、自局から最も遠い局を記録し「DX: JJ2YKR-2 35.29.80N 137.15.28E 46.8 km 80deg 08:20」の形で送ります。送信は最短 10 分間隔で、その間に記録が伸びたら 10 分後に最新を送ります。

更新

公開ページ (GitHub の kisaxi-release) の最新リリースを確認し、新しい版があれば画面上部に表示します。自動更新をオフにしている間は、画面上部の表示か「このソフトについて」の「更新して再起動」を押したときだけ入れ替えます。入れ替え中は TNC・APRS-IS が一時的に切れます。「今すぐ更新を確認」は設定に関係なく使えます。

その他

RF・APRS-IS で受信した局とパケットをこの時間保持します。アプリを再起動しても引き継がれます (既定 60 分)。

軌跡は区切りのところで線を切って描きます。受信範囲の外に出て戻ってきた局などで、離れた点どうしが直線で結ばれるのを防ぎます (既定は日付が変わったら)。
